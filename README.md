# UI-автоматизация Sauce Demo (Playwright)

Проект по автоматизации UI-тестирования веб-приложения [Sauce Demo](https://www.saucedemo.com/) с помощью Playwright и pytest.

**Автор:** Викторов М.С.

---

## Что демонстрирует проект

Автоматизация пользовательских сценариев интернет-магазина через браузер:

- Автоматизация UI на **Playwright** (Python)
- Позитивные и негативные сценарии
- Работа с локаторами (data-test атрибуты, CSS-селекторы)
- Взаимодействие с элементами: ввод данных, клики, выпадающие списки
- Проверки состояния страницы (видимость, текст, URL, количество элементов)
- Фикстуры pytest для подготовки тестов (открытие сайта, авторизация)
- End-to-end сценарий (полный путь оформления заказа)

| Файл | Содержимое |
|---|---|
| `test_login.py` | Тесты авторизации (позитивные и негативные сценарии) |

---

## Покрытие

### Авторизация (`test_login.py`)
- Успешный вход с валидными данными
- Вход с неверными данными → сообщение об ошибке
- Пустое поле логина → ошибка «Username is required»
- Пустое поле пароля → ошибка «Password is required»

### Каталог и корзина (`test_cart.py`)
- Добавление товара в корзину → счётчик обновляется
- Удаление товара из корзины → счётчик исчезает
- Сортировка товаров (по цене) → выбранная опция применяется
- Переход в корзину → проверка наличия товара и количества

### End-to-end (`test_end_to_end.py`)
- Полный сценарий покупки: авторизация → добавление товара → корзина → checkout → ввод данных → подтверждение заказа (с промежуточными проверками на каждом шаге)

## Запуск

1. Создать и активировать виртуальное окружение:
```bash
python -m venv venv
source venv/Scripts/activate    # Windows (Git Bash)
# source venv/bin/activate      # Linux/Mac
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
playwright install
```

3. Запустить тесты:
```bash
pytest                # обычный запуск (headless)
pytest --headed       # с отображением браузера
```
